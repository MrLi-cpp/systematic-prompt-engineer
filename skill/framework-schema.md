## 扩展维度（按领域）

### 前端/框架学习

- **D9: API 设计模式**：组件接口、Hooks设计、状态管理范式
- **D10: 工程化实践**：构建工具、性能优化、调试技巧

### 数据库/系统

- **D9: 存储引擎原理**：B+树/LSM-Tree、事务机制、并发控制
- **D10: 分布式挑战**：CAP、一致性协议、分片策略

### 硬件/嵌入式

- **D9: 寄存器与总线架构**：内存映射、中断机制、时钟域
- **D10: 实时性分析**：WCET、调度算法、RTOS对比

## 使用规则

在 system-prompt.md 的"框架构建协议"中，当主题匹配某领域时，自动追加该领域的扩展维度到维度库中，标注【可选】或根据 DEPTH 标注【L3必选】。
