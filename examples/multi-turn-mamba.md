# 示例：Mamba 深度学习 — 多轮画像完整过程

## 场景设定

用户输入口语化需求，AI 通过多轮画像对话逐步确认信息，最终生成体系化提示词。

---

## 第 1 轮：初始需求

**用户输入：**
> 我需要深入学习 Mamba 架构。我不满足于浅层的介绍，我希望构建一个完整的知识体系。请你为我撰写一份"Mamba 深度学习提示词"。

**AI 处理：**
- 提取 TOPIC：Mamba 架构 / Selective State Space Models
- 推断 DEPTH：L2-L3（"深入学习"、"完整知识体系"）
- PERSONA：未知（未说明背景）
- BACKGROUND：未知
- 画像缺口：PERSONA 和 BACKGROUND 是关键级缺口，影响 D1/D2/D3 的详细程度

**AI 输出：**

```
[画像构建 · 第 1 轮]
我已理解的部分：
- 核心主题：Mamba 架构（Selective State Space Models）
- 目标深度：L2-L3（深入理解 + 完整知识体系）
- 其他：你提到"不满足于浅层介绍"——我理解你需要原理分析 + 代码实现层面的内容

为了生成最贴合你需求的提示词，我还需要确认：

1. [你的背景知识]：你之前学过 Transformer 或 RNN 吗？Mamba 的很多概念建立在这两者之上，
   如果已经学过，我可以跳过基础部分直接讲演进；如果零基础，我需要从注意力机制开始铺垫。

2. [你的身份/学习目标]：你是学生准备做研究，还是工程师要在项目里用？
   这决定我侧重理论推导还是工程实践。

3. [输出格式]：这份文档最终要导出成 Markdown 网页阅读，还是 PDF 打印，还是 PPT 汇报？

你也可以说"直接生成"跳过追问，或补充任何你觉得相关的背景。
```

---

## 第 2 轮：用户回答 + AI 追问

**用户输入：**
> 1. 我学过 Transformer，对自注意力机制比较熟悉。RNN 也了解一点，但不太深入。
> 2. 我是研一的学生，导师让我调研这个方向，准备写一份调研报告。
> 3. Markdown 就行，我直接给 Kimi 用。

**AI 处理：**
- 更新 BACKGROUND：已学过 Transformer（深入），RNN（基础）
- 更新 PERSONA：研一学生，科研导向，需要调研报告
- 更新 OUTPUT_FORMAT：Markdown，给 AI 执行用
- 推断 LEARNING_GOAL：research（调研报告）
- 推断 IMPLICIT：需要论文来源、前沿进展、学术脉络
- 新缺口：STACK 未知（是否要写代码？），TIME_BUDGET 未知
- 置信度：0.7（核心维度已确认，还差技术细节）

**AI 输出：**

```
[画像构建 · 第 2 轮]
已更新的画像：
- 核心主题：Mamba 架构
- 目标深度：L2-L3
- 你的背景：已深入学过 Transformer，RNN 基础
- 你的身份：研一学生，科研导向，写调研报告
- 输出格式：Markdown（给 AI 执行）

还有 2 个小问题，帮我确认一下：

1. [代码需求]：你需要提示词里包含可运行的 PyTorch 代码吗？还是只需要伪代码理解结构就够了？
   调研报告的话，通常伪代码 + 结构说明就够了，但如果你想复现实验，需要完整代码。

2. [范围偏好]：Mamba 有很多变体（Vision Mamba、Mamba-2/SSD、MambaByte 等），
   你希望全部涵盖还是聚焦原始 Mamba（Gu & Dao 2023）？

说"够了"可以直接进入生成。
```

## 第 3 轮：最终确认

**用户输入：**
> 1. 伪代码就够了，我不需要跑代码。
> 2. 聚焦原始 Mamba，变体简单提一下就行。

**AI 处理：**
- 更新 STACK：不需要代码运行，伪代码即可
- 更新 DEPTH：降至 L2（调研报告 + 不跑代码 = 原理分析为主）
- 更新 CONSTRAINTS：聚焦原始论文，变体简要提及
- 画像置信度：0.95（信息完整）
- 状态流转：GATHERING → DRAFTING

**AI 输出：**

```
[画像确认]
基于我们的 3 轮对话，我已构建以下画像：

- 核心主题：Mamba 架构（Selective State Space Models）
- 目标深度：L2（原理分析 + 伪代码，不跑代码）
- 你的背景：已深入学过 Transformer，RNN 基础
- 学习目的：研一调研报告，科研导向
- 输出格式：Markdown（给 Kimi 直接执行）
- 范围约束：聚焦原始 Mamba（Gu & Dao 2023），变体简要提及
- 特殊偏好：不需要可运行代码，伪代码理解结构即可

如果以上画像有不准确之处，请告诉我，我会调整。
如果确认无误，以下是最终体系化提示词：

---

[画像确认后，AI 输出最终体系化提示词——与之前的 single-shot 版本相同，此处省略]
```

## 对比：Single-Shot vs Multi-Turn

### Single-Shot 版本（之前）

输入 → 输出，无追问。

**问题**：
- 不知道用户是研一学生还是工程师 → 内容侧重可能偏差
- 不知道用户 Transformer 水平 → D1 可能讲太多或太少
- 不知道是否需要跑代码 → D6 代码密度难以把控

### Multi-Turn 版本（现在）

3 轮对话后画像完整 → 输出。

**优势**：
- 确认用户是研一 + 调研报告 → D5 增加论文脉络，D4 增加学术对比
- 确认 Transformer 深入 → D1 跳过注意力机制铺垫，直接从"Transformer 的 O(n²) 瓶颈"开始
- 确认不需要跑代码 → D6 用伪代码而非 PyTorch，降低复杂度
- 确认聚焦原始 Mamba → D5 变体部分缩短，不喧宾夺主

## 澄清模式示例

如果用户回答有矛盾：

**用户输入（第 2 轮）：**
> 我零基础，但我也看过几篇 Mamba 的论文。

**AI 处理：**
- 矛盾："零基础" vs "看过几篇论文"
- BACKGROUND 无法确定：是 zero 还是 intermediate？
- 状态流转：GATHERING → CLARIFYING

**AI 输出：**

```
[画像澄清]
我注意到一个矛盾：你提到"零基础"，但同时又"看过几篇 Mamba 的论文"。

为了准确画像，我需要确认：

你所说的"零基础"是指：
- A) 对 Transformer/RNN 等前置技术零基础，但直接看了 Mamba 论文？
- B) 对所有深度学习框架和概念都零基础，论文也只是粗略浏览？
- C) 其他：___

这个区别很重要，因为它决定我是否需要从"什么是神经网络"开始讲，还是从"注意力机制的瓶颈"开始。
```

用户澄清后 → 更新画像 → 回到 GATHERING 或进入 DRAFTING。
